# Web Studio Landing Page

A static landing page project built with HTML and CSS.

## Overview

This project is a simple marketing website for a fictional web design studio called **Web Studio**. It demonstrates responsive page structure, typography, and visual sections for a hero, services, team, portfolio, and footer.

## Files

- `index.html` — main webpage markup
- `css/styles.css` — project styles
- `images/` — image assets used for the team and portfolio sections
- `.gitignore` — files and folders ignored by Git
- `prettierc.json` — Prettier formatting configuration

## How to view

1. Open `index.html` in a browser.
2. Alternatively, use a local development server if preferred.

## Notes

- The page uses Google Fonts and Normalize.css via CDN.
- The layout and styling are implemented purely with HTML and CSS.
